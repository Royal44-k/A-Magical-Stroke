# 神笔马良：奇幻一笔 · v5.0

面向小学四至六年级的四章互动教学案例。神笔贯穿“画一画—试办法—改一笔—说发现”。学生先自由作画，再用清楚的功能图纸检验办法；作品、预测、执行结果和修改过程组成个人画册。

## 四段奇遇

| 故事 | 亲手做什么 | 学习与迁移 |
|---|---|---|
| 一笔清泉 | 参照精美图页，选择水车、竹槽或蓄水池作画；画连通水道、分次开闸 | 合理用水、材料限制、数量守恒；旱天水少了，重新安排 |
| 田里的好帮手 | 画耕牛、选窄犁或可折宽犁、画行走路线；画中的牛沿路线回放 | 方向、面积、转弯与体力；避开幼苗和石头，比较雨天方案 |
| 石磨转起来 | 画磨坊、用齿轮笔配大小轮、沿圆圈摇柄，再分实际磨出的面粉 | 观察传动、比例与资源分配；硬粮更难磨，讨论不同家庭的需要 |
| 借风回家 | 画船、围出船帆、从船边画风、收放船帆 | 面积、方向、分步计划；看清右上方码头，避礁并应对大风 |

每章有两种情境和清楚的结尾。失败指出具体原因，允许修改；成功反馈引用实际结果。画得像不像、笔画多少不作为通关门槛；自由画不冒充任意图像识别。程序核对规则，老师与伙伴观察表达、创意和理由，不给人格打分。

## 使用

Windows课堂交付包双击“启动奇幻一笔.cmd”，内含Node运行时，默认端口4185。工作区预览由制作方启动。

源码开发：`npm run build`、`npm start`。核心验收：`npm run test:v5`、`npm run test:v5:browser`、`npm run test:v5:detail`、`npm run test:sites`。交付包无需联网即可运行主要教学环节；源码重建需要先安装依赖。

## 作品与兼容

- v5独立存档：`maliang-qihuan-scroll-v5`；每种情境保留最近24份检验快照。
- 自由画、功能图纸、最初猜想、执行结果、三项反思、交流记录一起导出为可离线阅读和打印的HTML画册。
- `?edition=4.0`、`?edition=3.1`、`?edition=archive`保留旧画卷。另开v5画卷需确认，不删除旧版作品。
- 鼠标、触屏可作画；核心拖曳和手势提供点选或键盘替代。WebGL不可用时降级为平面图，任务仍可完成。支持减少动态效果。
- 不收集学生姓名、摄像头或录音；服务端AI接口保留，核心教学反馈不依赖外部大模型。

## 媒体与技术

新增矿物青绿画卷村庄、透明马良人物与四张绘画参照图。Three.js分层舞台呈现透视和轻柔动效；教学图纸用可操作的Canvas/SVG表达。已有两段8秒剧情影片及字幕可在清泉开场观看。13个新镜头已提供生产规格，本轮没有生成新的剧情视频。

React、Three.js与Pointer Events本地打包，不使用运行时第三方CDN。借鉴用户录屏的深墨留白、青绿朱砂淡金和分层构图，未复制参考视频及网站的成品素材或代码。游戏中的力气、推力、步长是明确的教学规则，物理解释边界见教师指南。

完成程序和浏览器验收，尚未开展真实小学课堂试教。课堂应结合解释、修改与迁移表现判断学习情况，不能把通关当作学习效果证明。
