# 神笔马良：奇幻一笔 · v5.0

面向小学四至六年级的互动教学案例。孩子执起神笔，画出自己的办法，在故事里试一试、改一改，再把发现收入画册。

![奇幻一笔 v5.0 实际首页](artifacts/v5.0/qa-home-final.jpg)

## 四段奇遇

| 故事 | 孩子亲手做什么 | 可以学到什么 |
|---|---|---|
| 一笔清泉 | 看参照，画水车、竹槽或蓄水池；画水道、分次开闸 | 观察结构，合理用水，照顾田地与门前的人家 |
| 田里的好帮手 | 画耕牛，选宽窄犁，规划路线，看自己的牛沿路耕田 | 辨认方向，计算面积，比较走法与体力消耗 |
| 石磨转起来 | 画磨坊，拖画齿轮，转动摇柄，再分实际磨出的面粉 | 比较齿轮传动，用数量和分数说明分配办法 |
| 借风回家 | 画船和帆，从船边画风，收放船帆绕过礁石 | 认识图形与面积，安排多步行动，送大家平安归岸 |

每章都有新的条件：水少了、雨后地软了、粮食更难磨了、海风变大了。学生需要重新想办法。结尾回应实际结果，指出可以改进的地方，并保留作品、最初猜想、试做和交流记录。

画得像不像、笔画多少不作为通关门槛。功能图纸按公开规则检验；创意、表达和理由由老师、伙伴与学生一起讨论。鼠标、触屏和键盘均有操作方式，支持减少动态效果；WebGL不可用时仍可使用平面任务图。

## 启动

源码需要先安装 Node.js（22 或 24），在项目目录执行：

```sh
npm ci
npm run build
npm start
```

打开 [http://127.0.0.1:4185](http://127.0.0.1:4185)。开发时可使用 `npm run dev`。

Windows课堂使用可下载 [v5.0 Release 离线交付包](https://github.com/Royal44-k/A-Magical-Stroke/releases/latest)，解压后双击“启动奇幻一笔.cmd”。**Release离线包包含Node运行时；本仓库源码不包含运行时和已安装依赖。** 主要教学环节、图片和影片可在本机离线使用。

## 作品与验证

作品保存在当前浏览器，可导出离线HTML画册并打印；每种情境保留最近24份检验快照。另开画卷前可先下载作品。不采集学生姓名、摄像头或录音，核心反馈不依赖外部大模型。

```sh
npm run test:v5
npm run test:sites
```

浏览器检查另需Playwright与Edge环境，命令为 `npm run test:v5:browser`、`npm run test:v5:detail`。已完成的检查与证据见[验收记录](docs/47-v5.0-测试验收.md)；尚未进行真实小学课堂试教，不将程序测试等同于学习效果验证。

React、Three.js、Canvas/SVG与Pointer Events共同实现画卷、自由笔迹和操作反馈。部分文件名仍带有较早的版本号，它们是当前工程复用的源码或资源，不表示本仓库发布多个版本。
