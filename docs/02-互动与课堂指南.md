# v2.2 互动与课堂指南

建议小学四至六年级，两课各约35—40分钟；单次体验可用20—30分钟完成主线，课堂时间需留给讲述和讨论。此时长是教学安排建议，未经过学生实测。

## 教学目标与可观察证据
|目标|学生做什么|教师看什么|
|---|---|---|
|把想法画成可用的办法|画伞、试雨、修改|能指着实际漏雨处解释改动|
|兼顾不同使用者的需要|水到田边，还要给人留路|能说清绕路或搭桥解决了谁的难处|
|读懂选择后的条件|展开卷轴，选择或重谈|能分清“今天领粮”和“以后用水”的关系|
|把做法说清、交给别人|排纸牌、指认三处、提水停水、收好工具|能根据实际水路和工具状态解释为什么要按顺序做|
|用实际经历表达|选画册里的前后画稿讲述|说出“我先……试过发现……所以又……”|

## 课堂节奏
第一课：用原作阅读或口述引出神笔（5分钟）；雨夜自由创作与试验（8分钟）；听村里人说话、画水路、重试或拼桥（15分钟）；两人交换观察（7分钟）。
第二课：回到已保存的画卷（3分钟）；阅读卷轴与商量（10分钟）；交接排序、查看和动手试做（10分钟）；看结尾、修补一处（7分钟）；展示画册和口头表达（8分钟）。

课堂提问：“雨滴在哪里停了？”“水到了以后，谁还有难处？”“换一个选项，先前答应的话就不算了吗？”“如果你是接手的人，第一步会做什么？”先请学生指着自己的记录说，不抢先给统一答案。

## 多种操作，同一个学习目标
自由画支持鼠标与触屏；连点画支持点击、触屏、方向键和回车；拼桥有拖放和选块后点空位；对应需要有拖放和两次点选；排序有拖放及往前/往后按钮；收工具支持拖入篮子，或先选工具再点篮子，键盘同样可用；视频由学生播放，提供中文字幕和旁白；小禾提示及设备朗读可选。减少动态模式保留结果，不强制观看动画。

无需姓名、麦克风、相机或账号。学生作品保存在当前浏览器；不同浏览器和端口的作品互不通用。共享设备换人前，先下载画册，再从首页“另起一张画卷”开始。旧版本作品从教师页的历史入口查看，不自动删除。

## 评价和边界
不按画得像不像、花了多久、重试几次或先帮助谁计分；不用人格或品德排行榜。作品可不完整，但表达需要具体。连通检测允许少量落笔误差，不是工程设计软件；模型不计算真实水压、流速、桥梁受力或防水材料性能。教师可用纸条、水槽等安全课堂材料做后续观察；真实搭桥、水边实验由成人安排。

## 真实使用验证仍需课堂开展
本次完成程序、浏览器与视觉验收，未声称已有学生课堂试用数据。建议首轮邀请6—8名不同操作熟练度的学生，在教师在场的情况下观察：能否独立开始画、漏雨后是否知道改哪里、是否发现门前需要、能否解释条款的后果。只记任务表现，不收集身份信息。根据具体卡点再调整。

## v2.1：用两张真实试画说清改动
试水时先跟着水看，再点“停一停”观察一处；重看不会增加试次。水到田边不代表门前也通，要看接上的支路。打开画册后选“我画的水路—两次放一起”，拖动画纸中间的分界线；也可用滑块方向键，或分成两张看。请学生同时读当时的支架、提水和试桥记录，区分改画与准备变化。离线画册会带走这些依据。

## 交接时看什么
请学生说：“我指给小禾看的三处是……”“水没到田边就停，会怎样？”“工具收在哪里，下一个人好找？”可两人交换讲解与操作，应用不要求录音或输入姓名。水迹动画仅帮助观察连通关系，没有真实流量和浇水量计算，不把绿芽作为现实作物立即长大的科学结论。无需比谁停得快；减少动态模式直接显示到田，继续完成停水和收工具。
