# 《神笔马良：奇幻一笔》v2.1 完整故事执行稿

小学四至六年级。借用洪汛涛《神笔马良》的文学主题创编。主角马良、小禾、鲁伯、周婶和大官保持既有造型；学生是执笔的人。全程不按画得像不像或先照顾谁评分。

## 第一幕：雨夜，画一把伞

窗外细雨落在瓦上。小屋的桌边，马良守着一张画纸。笔杆微微发亮。旁白：“雨落进小屋。桌上的笔，忽然亮了。”马良把画纸往怀里一收：“要是有一把伞，就好了。”小禾轻声说：“现在，换你来画。”

学生在纸上亲手画伞。鼠标、触笔或手指可以自由画；也可连点，或用方向键移动笔尖、回车落笔、Escape提笔。四种颜色、三种粗细、撤回、放回、重新画、小禾局部示范均可用。示范只给起笔，不替学生完成整幅画。

点“画好了，试一阵雨”，七列雨滴落向下方画纸。雨滴遇到实际笔画就停，没挡住的雨落在纸上。宽度不足时提示具体漏雨方向；完成后回应“雨滴被你的伞面挡住了，画纸还是干的！”学生可以继续加花纹、修改，或带着尚未解决的问题前往河边。试过的每张画连同结果进画册；当前画另存。

转场：雨渐停，光从山后升起。马良带着神笔来到河边。课堂可问：“你改了哪里？雨滴告诉了你什么？”不要求画成统一形状。

## 第二幕：给水画一条路

早晨的河水流得很快，田却在高处。屋门前有人提篮来往。旁白：“河里有水，田却比河高。门前，还有人来往。”

学生可以依次听三个人说话：
- 小禾：“田里的苗渴了，水能送上去吗？”
- 周婶：“门口是大家每天走的路，别挡住呀。”
- 鲁伯：“我来把水提到高处。你给它画一条路。”

先请鲁伯装稳支架，选择水流推轮或大人轮换提水。两种安排均可行，不设快慢或品德排名。画纸左边为出水口，右上方为田边，中央浅褐色区域为门前的路。学生画出的每条线就是水路；水滴沿实际相连的线前进，也会流入接通的支路。到达田边以后，仍要检查门前有没有水经过。

可能结果：
1. 没装稳支架或没选提水办法：水还未提起，提示回到相应准备。
2. 没接出水口：提示从左边蓝圆圈接着画。
3. 中间断开：水停在可到达处，学生看见断开的两头，添一笔再试。
4. 已到田边但挡住门口：水到了，大家却过不去。可以撤回重画绕路，也可拼桥。
5. 水到、路通：小禾确认两个需要都照顾到了。

拼桥支线：左支架、桥面、右支架须就位，桥面横放。拖放与点选均可。缺支架、缺桥面、方向错误都有对应提示。小禾实际试走通过后，再回水路检验。改变水路或桥，旧结果和旧交接确认失效，需按新图再试。

转场：大官带粮袋来到村口。水路图原样收进画册，后续不能用预制图替代学生笔迹。

## 第三幕：画笔交给谁

大官把粮袋往前一推：“神笔以后听我安排，粮食今天就分。”卷轴上方写着“今日分粮，共修水车”。学生展开下面，才看见：“神笔听我安排。往后用这架水车，得先在约定上签字。”

三个方向：
- **先领粮，再想办法。** 粮食能救急，取水须签字的条件也留下。神笔仍由马良执笔，但以后的用途被约定限制，避免“笔已拿走却还能作画”的情节矛盾。
- **笔留下，另想办法。** 不答应这条限制。鲁伯说：“粮食的难处，我们一起再想办法。”不会因此获得“更善良”标签。
- **先把话问清楚。** 将“田里缺水—大家轮流取水”“门前要走人—留一条能走的路”“马良明天不在—把做法教给接手的人”对应起来。

对应可以拖，也可先选需要、再选办法。错配会提示重读，两边全对后仍需点“请大家一起说好”。确认后约定不用另外签字，按商量好的次序取水。已领粮时答应的条件不会因换点“拒绝”或“商量”而消失；须真正完成重谈。

转场：小禾指着画说：“说好的事，还要让下一位知道怎么做。”

## 第四幕：交给下一双手

村口木牌边，大家围着画纸。小禾：“把做法教给我。明天换个人，也能接着用。”

先选不同的两位大人：一人平时带头，另一人接手。学生把四张纸牌排成“看看支架和水路—开始提水—停下水车—收好工具”。可拖动，也可点往前、往后。

排好后，进入同一张真实水路的试做桌。小禾依次执行当前纸牌，不会绕过顺序错误。

1. 查看：学生分别指出支架、水路和门前。结果来自第二幕当前画稿和准备；没有试通的水路不能显示交接完成，给出回水边修改的入口。
2. 提水：学生请大人开始提水，水车转动，水迹沿学生笔迹向田边走。田边到水后才出现绿芽，减少动态模式直接呈现同样结果，不依赖动画猜答案。
3. 停水：学生请大人停下水车。提前停下则田边未到水，保留三处查看记录，回到提水这一步重试；不扣分，也没有倒计时比赛。
4. 收好：用过的水桶、绳子、木尺放在工具区。拖进工具篮，或选一件再点篮子；键盘也可完成。每件只计一次，三件收齐才显示完成。

小禾用具体句子回应：“水还没到田边就停了”“田边已经到水，水车也停稳了”“水桶收好了”。图上水车、到田水迹、绿芽和工具状态与文字同步。改纸牌、换人、改水路或桥，须从头再试；旧版已完成的作品保留原记录，可自愿重新体验。

学生可以带着未完成的交接去看看结尾，不用困在某一关。

## 第五幕：看看这一回

结尾先显示这一回的后果，再摆出学生亲手画的伞和水路。不是抽象评分页。显示三条实际状态：水与通行、取水条件、交接是否试完。

|结尾|触发条件|旁白与启示|修补入口|
|---|---|---|---|
|大家都会用了|水路检验通过、没有取水限制、交接完成，之前未留下问题结尾|“你的画把水送到了田边。做法也留了下来，下一双手能接着做。”能力的价值包含让别人也会用。|仍可回去重画、重谈、重试|
|这一笔，补好了|曾出现问题结尾，后来三件事都完成|“原来的问题没有藏起来。你回去添了一笔，也把办法改得更周全。”允许修改是学习的一部分。|继续保存前后真实画稿|
|木牌还挡在路上|已答应的取水条件仍未解除；优先于其他未完成项|粮袋留下了，条件也留下了。观察眼前收获和以后的影响。|再去谈一谈|
|还有一处，等你来画|没有取水限制，但水路或交接尚未试好|带着一个具体问题再试，不贴失败标签。|回去添一笔／再请小禾试试|

学生可写一句发现，也可说给同伴听。画册保留当前笔迹和最近12次试画，导出单张SVG或带故事与记录的离线HTML。老师不必要求每位学生都走到同一结尾。
