# 素材、字体与许可

## 本项目图像
16张在用图片由本项目通过内置图像生成工具制作；文件、尺寸、用途、SHA-256和生成提示词路径见assets.json。情境图12张，首页横竖构图2张，透明小禾1张，雨夜道具近景1张。没有下载他人影视片段或书籍插图充当本项目场景。

night-brush-v1.png为灯具修订前归档，当前页面、分镜和交付素材只使用night-brush-v2.png。art-direction/selected-scroll-v2.png是用户选择的第1种长卷方向、按正式标题更新后的视觉目标，不把整张界面截图当按钮使用。

图像内的人物与场景负责叙事，水槽SVG、连线SVG和手绘canvas负责可操作模型/真实学生笔迹；它们不冒充生成的场景美术。
