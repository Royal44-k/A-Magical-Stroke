# v2.2 技术与接入

运行：Node内置HTTP服务server.mjs，默认127.0.0.1:4185。设置PORT可改端口。dist/client为本地/浏览器静态内容；Sites适配文件保持原样。所有视频本地托管，支持HTTP Range拖动播放。

存档：v2键maliang-qihuan-v2；历史键maliang-qihuan-v1不迁移、不删除。当前作品、最近12次试画、实际准备和桥、条款、交接、结尾、短句均存当前设备。初始状态校验不通过时从新画卷开始。保存失败时显示提醒，请下载画册。

AI：沿用/api/capabilities与/api/guide。配置AI_BASE_URL、AI_API_KEY、AI_MODEL于服务端环境或交付包.env；只有stage、waterReady、handoffReady、exclusive发送给已配置模型，不发送笔迹、姓名或学生短句。AI不判断答案，不改变状态；失败或超时继续本地提示。模型名称由账户实际可用项决定，不在学生界面写固定型号。未配置在线服务时不声称已联网。

影片：public/video/v2-manifest.json只列实际存在的本地文件。MP4 H.264/AAC、1280×720、24fps；字幕WebVTT。影片故障不堵住作画。图像源、角色连续性、导演稿与分镜一并交付。

验收：tests/v2-engine.test.mjs检查真实笔迹、断路/挡路、修补、记录与导出；tests/v2-browser.mjs用真实鼠标、拖放、触屏、键盘走完整主线。tests/v2-media.test.mjs检查视频与状态不互相冒充。历史规则和Sites适配单独回归。

依赖：学生运行仅需交付包内的Node，不需安装视频制作工具。开发构建依赖见根package-lock.json；film-v2为可选再制作源，GSAP与Hyperframes版本在其说明内。不存在前端API密钥。

交接扩展：handoff.practice.rules=22，保存三处查看、是否转动、是否到田和已收工具。旧未完交接从观察步骤续试；旧已完成记录以legacy标记保留，不假称新操作已做过。改水路、准备、桥、人员或纸牌清空本次试做证据。新增tests/v22-handoff.test.mjs与tests/v22-browser.mjs覆盖规则和操作。
