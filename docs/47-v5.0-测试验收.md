## 学习机制边界

1. 画稿保留到执行和画册，但不会声称识别任意自由画的内容。功能规则由水路、犁路、齿轮和帆面等明确图纸驱动。
2. 每次检验保存当时图稿、预测和结果；修改当前作品不修改历史。开闸和摇柄后，动手前预测不可倒填。
3. 初次尝试与新条件可来回比较。新条件未检验的作品在切换、刷新后仍保留。
4. 只按清楚的任务规则反馈，不按笔画数、速度、人格或创意自动评分。教师观察量规见46号文档。
5. 新绘画不是通关形式门槛。学生可以先试功能、再回画纸补充；不把缺少画面误判为学科能力不足。
