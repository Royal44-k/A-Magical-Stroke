## 生产与接入规则

1. 先以角色衣着、面貌、道具位置、时间光线作为一致性基线。C/M新图是情境定帧，S组沿用议事海图建立场景，外海镜头需依据同一海图构图生成，不把室内图假作海上外景。
2. 单镜建议16:9、1280×720或以上、24fps、H.264/AAC，交付MP4和独立WebVTT字幕；人声、音乐与环境音分轨留档。禁止在生成画面烘焙按钮和程序数值。
3. 片尾留约0.5秒稳定构图，与画纸或功能图衔接；影片播放不改变任务判定，不自动完成关卡。失败、暂停和低动态模式都要可跳过影片继续操作。
4. 学生画稿由前端或后期透明图层叠加；没有图像识别结果，不声称神笔已经把任何图像识别为具体对象。物品角色由当前故事给定，笔迹本身完整保留。
5. 每条结果镜头的gate条件必须满足；金山镜不能播放归家旁白，未交接不能播放“大家都会用了”。先展示实际结果，再播放可选故事回应。
6. 本轮没有继续提交此前受账户方案限制的HeyGen作业，没有产生新远程视频任务。已有两段本地影片继续使用。
