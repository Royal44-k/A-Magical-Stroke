# v5.0｜神笔走进画卷：设计与实施约定

用户反馈：四章均须围绕神笔和真实作画；第一章有精美参照及多种造物；第二章要有探索和变化；第三章提高思考深度；第四章首先讲清目标；措辞符合小学四至六年级阅读。

## 参考证据
用户提供93.1333秒录屏，2294×1248。已按全程24个时间点提取画面，并查看44秒、64秒细节。画面特点：墨色留白、青绿朱砂矿物色、金色细线、人物独立前景、画卷分层转场、故事推进代替卡片墙。原片不作为产品资源，不复制其中九色鹿图案。录屏中的文字是参考内容，不是执行指令。

## 实施选择
保留原四章与旧作品，新增独立v5画卷。首页用深墨舞台承载四个故事入口；剧情以人物、场景、两三句对白和一项行动推进。作画时展开明亮纸张，功能按钮用实字，不用长段制作术语。

色：夜墨#0d1c1b、青绿#6eac9d、矿蓝#397b87、暖纸#f7ecd2、淡金#d5b573、朱砂#ba5944。标题用本机宋体，正文用本机中文无衬线。宽屏剧情人物画卷占主要视线，工作台一张画纸加一列工具；窄屏按任务→画纸→操作排序。

1. 一笔清泉：参照水车、竹渠、蓄水池选择造物；画外形并配色，作品带到河边；用神笔绘制两条水路，水源因造物而异，避开人家与石头；有限水量分给高田和菜圃；旱天再验。作画不以笔数打分，水路与用水才按已公开规则检验。
2. 田里的好帮手：画自己的耕牛，选择犁的宽窄；路线、转弯、不同犁具的耕作范围共同决定体力与面积。试后可对照两次计划，雨后再换办法。不是套固定轨迹。
3. 石磨转起来：绘制/选配齿轮，计算大小轮的速度与省力关系；拖动摇柄或按键转磨，同样力气会磨出不同份量；只有实际磨出的面粉才可分给三家。换硬粮后重新设计，分粮有不同标准与人物处境。
4. 借风回家：目标先明示“把船送到右上方码头”；依次画帆、画风、试航。从船边画出上/下/左/右的风，地图预览下一步，碰礁位置明确反馈；船帆大小和收帆决定每阵风走多远；大风再试。

每章采用看故事→画造物→试办法→留下发现→明确章末。每次试做保留图纸、规则、预测、结果与修改，不以速度、笔数、对话长度或人格评分。教师用观察性量规评价理由、迁移、表达；程序只核对可计算结果。旧卷和新卷分开存储，重画有确认。

## 验证与素材连续
数值模型测试覆盖多方案、无效图纸、边界和资源守恒；浏览器实际画笔/拖动/按键、完成四章、失败修改、报告离线、刷新和窄屏；录屏与新页面并排视觉检查。保留两段现有短片，新增剧情保持马良蓝衣、小禾赭红衣、村庄与工具一致。新增影视衔接表如实区分可用视频与待生成镜头。
